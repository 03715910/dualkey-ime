# 0.1.11 入力・候補・貼り付けの改善

## 候補一覧

「一覧」を開くと背景で候補を取得し、連続スクロールで閲覧できます。「見る」「次の50件」などの追加ボタンはありません。RecyclerViewで表示するセルを再利用し、候補をタップすると確定します。初回検索は最低64件で、以前の30件設定でも一覧が止まりません。入力中の最初の検索数は設定できます。

検索は無制限ではありません。文節探索のビーム幅は96のまま、辞書の直接一致と補完を含む検索の保護上限を10,000件としています。すべての読みで10,000件の候補があるわけではなく、あり得る全文の組合せを全列挙する機能でもありません。長い検索は背景で実行し、入力が変わった後の結果は適用しません。

## 英語・カタカナ・記号

従来の日本語辞書とJMdict由来の意味に対応する英語・カタカナ候補を維持し、Mozcの公開記号辞書を別途追加しました。1,871の読みと5,991の読み・記号の組に対応します。「おんぷ」の♪・♫・♬、「から」「ー」の〜・～はその一部です。U+301Cの波ダッシュを含む項目へU+FF5Eの全角チルダも追加する規則を使い、例示単語だけの専用登録にはしていません。

記号一覧からも「〜」「～」を直接入力できます。「カナ/英」は未確定文字列全体をカタカナ→意味の英語→ひらがなへ切り替える従来の機能です。確定済みの文章には適用しません。日本語QWERTYでは下段にも配置しています。英語の訳語には多義性があります。未登録の文の翻訳は既存のML Kit操作を使います。候補を出すたびにモデルをダウンロードする処理は追加していません。

記号原本・ライセンス・取得元・ハッシュは`app/src/main/assets/symbols/`に同梱し、`python tools/build_symbol_dictionary.py`で索引を再生成できます。

## 予測と学習

一般辞書の単語コスト・品詞接続に、接頭辞補完、共通表現、直前の語との組合せ、利用頻度・最終使用時刻を合わせます。「おは」から「おはよう」「おはようございます」、「今日は」の確定後に「いい天気ですね」などを、個人の学習なしでも提示します。生成AIの言語モデルやMozcネイティブ本体を新たに組み込んだものではありません。自由な文脈理解や一般IMEと同じ変換品質の保証はありません。

新しい学習では辞書で確認できる単語・語句へ分割し、単語の読み・表記・回数・時刻と隣接する語の組合せを保存します。任意の長い入力文をそのまま記録しません。単語単位の重みは文章の内部の候補生成にも適用します。過去の辞書で裏付けられない丸ごとの記録は順位付けへ使わず、保存済みデータは勝手に消去しません。「変換と辞書」で学習のON/OFF・全削除と、ユーザー辞書の追加・編集・削除ができます。削除前に計画された学習が後から復活することも防ぎます。

パスワード・数値・URL・メール・学習禁止欄の保護を継続します。入力内容をサーバーへ送信する処理、キー入力ログは追加しません。

## 4つの画面配列とShift

「設定 → 入力とサイズ」で日本語は12キーフリック／ローマ字QWERTY、英語はQWERTY／12キーフリックを別々に選べます。英語フリックは電話型のABC・DEFなどのグループで、中央・左・上・右へ先頭から順に文字を配置します。キーを押すと候補の方向をプレビューします。数字行は独立です。日英の切り替えは下段のボタンを使います。

英語の画面Shiftは⇧（小文字）／⬆（次の英字1文字）／⇪（大文字固定）です。1回押して次の英字を入力すると戻ります。入力前に間を空けてもう一度押すと解除、ダブルタップすると固定します。別のキー操作を挟むとダブルタップには数えません。物理Shift・Caps LockはAndroidのキー状態を使います。画面配列の設定は物理ローマ字入力と独立しています。

## 削除とEnter

削除のタップは従来どおりです。長押しは選択範囲を優先し、未確定の範囲があれば全部、確定後はカーソル直前の句読点区切りを削除します。カーソル後方へは広げません。改行直後は改行だけを削除します。前方の取得は2,049文字までに制限し、切れていて範囲を確認できない場合、パスワード・数値欄は1文字へ留めます。長押し後にタップ削除を重ねません。

画面Enterの初期値は、チャットの送信アクション・複数行欄では改行です。未確定の日本語は最初に確定し、次に押すと改行します。物理Enterはまず変換確定し、確定後はSEND対応を通知する入力欄で`performEditorAction(SEND)`を使います。物理Shift＋Enterは通常の文章欄で改行します。検索・URL・パスワードなどの構造化した欄では入力先のアクションを優先します。画面と物理の動作は設定で変更できます。

LINEなどがSENDを公開するか、実際に送信を行うかは入力先の仕様に依存します。通知されていない送信ボタンを自動クリックしたり、アクセシビリティで操作したりしません。[EditorInfo](https://developer.android.com/reference/android/view/inputmethod/EditorInfo)・[InputConnection](https://developer.android.com/reference/android/view/inputmethod/InputConnection)の公式APIだけを使います。

## 貼り付けと履歴

上部の重複する日英切り替えボタンを「貼り付け」に置き換えました。タップで現在の文字列を貼り付け、長押しで履歴を表示します。履歴の項目を押すと貼り付け、個別の削除と全削除もできます。上部の縮小・翻訳・設定、物理キーボード時の通知・ショートカットによる表示切替は維持します。

履歴保存は初期OFFです。ONならDualKeyの通常入力中に取得できたコピーだけを、バックアップ対象外のアプリ内ファイルへ保存します。最大件数は5〜100件（初期20件）、1件2,000文字以内で、読込・表示時に24時間以内へ整理します。機密フラグ付きのコピー、パスワード・学習禁止欄、メール・URL・長い数字列などは保存しません。すべての機密情報を完全に自動識別できるものではないため、秘密の文を扱う場合はOFFを使ってください。

OFFにすると保存済み履歴も削除します。履歴を開いたり通常貼り付けをしただけでは削除した項目を再登録しません。Androidの現在のコピーは履歴OFFでも明示的に貼り付けできます。URI・Intent・画像の取り込みは行いません。OSの過去のコピー履歴全体を取得する機能ではありません。[Androidのクリップボード](https://developer.android.com/develop/ui/views/touch-and-input/copy-paste)・[機密クリップの扱い](https://developer.android.com/privacy-and-security/risks/secure-clipboard-handling)を参照してください。
