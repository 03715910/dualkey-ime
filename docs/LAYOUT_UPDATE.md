# 0.1.2のキーボード小型化

ユーザーから提供されたDualKeyとMicrosoftキーボードの画面画像を参考に、中央のかなと左右の操作キーを4段へ整理しました。他社の画像・アイコンは同梱していません。

| 項目 | 0.1.1 | 0.1.2の標準 |
| --- | --- | --- |
| 日本語のキー部分 | 5段 | 4段・5列 |
| 文字キーの高さ | 52dp | 40dp |
| 数字の高さ | 52dp | 30dp |
| ツールバー | 38dp・枠付き | 32dp・1行 |
| 候補欄 | 48dp | 32dp |
| かなの表示 | 方向の文字も常時表示 | 中央の1文字、押すと方向プレビュー |

標準の並びは以下です。数字行は独立し、設定で非表示にもできます。

```text
1 2 3 4 5 6 7 8 9 0
🌐   あ   か   さ   ⌫
◀    た   な   は   ▶
記号  ま   や   ら  空白
abc 小゛゜ わ   、   ↵
```

左右キーは未確定の変換候補も移動できます。確定済み文章ではカーソルを動かします。句読点のキーはフリックで「、」「。」「？」「！」「・」を選べます。

既に保存したキー高さ・倍率・辞書などを削除しません。標準値を使用中なら新しい40dpが適用されます。手動で高さを大きくしていた場合は、設定の「キーの高さ」を40dp、「全体の倍率」を100%へ調整できます。横画面は画面の高さに合わせて自動縮小し、キー文字も枠に収めます。

配布は従来と同じ[専用サイト](https://03715910.github.io/dualkey-ime/)とアプリ内更新を使います。同じ鍵で署名した0.1.2 / versionCode 5へ上書き更新します。アンインストールは不要です。実施結果は[テスト記録](TEST_RESULTS.md)を参照してください。Samsung実機・実物のBluetooth/USBキーボードは未検証です。
