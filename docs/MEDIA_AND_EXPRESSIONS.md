# 英語フリック・記号とメディア貼り付け

- 「設定 → 入力」で英語フリックを選ぶと、ABCの左に `@`、下段に `a/A` と句読点が出ます。句読点はタップで `.`、左 `,`、上 `?`、右 `!`、下 `…`。空白キーは右側の1つです。
- Shiftは1回で次の英字を大文字、すぐに2回で固定、固定中の1回で解除。1文字大文字の待機中に間を置いて押すと取り消せます。
- 日本語変換の通常候補に加え、「てん」で `・`、 「てんてんてん」で `…`、「おんぷ」で `♪` などが出ます。絵文字と顔文字は変換・予測設定で別々に変更できます。
- 「一覧」の下部で「すべて」「絞り込み」「絵文字」「顔文字」を切り替えられます。「絞り込み」は、読みの一致する単語・表記・記号を表示します。「にこ」からは `2個`、`２個`、`二個`、`ニコ` などを選べます。
- 日英の絵文字は [Unicode CLDR 47](https://github.com/unicode-org/cldr/tree/2ef784e3a4168bc2a43cd1b5b9839b6636f5899c/common/annotations) に由来します。読み、記号、顔文字は `app/src/main/assets/expressions/aliases.tsv` で拡張でき、CLDRデータは `python tools/build_expression_dictionary.py` で再生成できます。

「貼り付け」はタップで現在のクリップボード、長押しで履歴を開きます。メディアにはコピー元の読み取り可能な `content://` データと、入力先が対応する形式を宣言していることが必要です。[Androidのメディア入力API](https://developer.android.com/develop/ui/views/touch-and-input/image-keyboard)を利用するため、同じアプリでも入力欄によって対応が異なります。メディアがコピーされていない、または入力欄が受け取れない場合は、送信先アプリの添付ボタンや写真選択機能をお使いください。

キーボードを表示している間、コピーしたメディアを上部にプレビューします。画像やボタンをタップすると貼り付け、×で閉じます。履歴保存をオンにすると、貼り付け前にコピーしたメディアも文字と一緒に新しい順で表示されます。履歴は初期状態でオフです。

貼り付けや履歴のために保持するファイルは、専用の内部一時領域に置きます。上限は1件32 MiB、合計64 MiBです。メディアの保存期間は5〜60分で、初期値は10分です。履歴のメディア情報はIMEのプロセス再起動後に復元しません。期限切れの一時ファイルは起動時にも削除します。入力先アプリが受け取ったコピーの保存・送信は、そのアプリの操作に従います。
