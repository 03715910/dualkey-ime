# 0.1.7：英語・カタカナ候補と未確定文字列の切り替え

## 操作

- 日本語候補に、読みから検索した英単語と対応するカタカナ語を追加します。「いす」には「椅子」に加えて「イス」「チェア」「chair」が含まれます。候補一覧から通常と同じように確定できます。
- 日本語キー左上の「カナ/英」は、未確定の全文をカタカナ → 英語 → ひらがな → カタカナの順に切り替えます。英語の表示中も未確定のままです。
- 漢字を変換中なら、選択中の表記を英語検索の手掛かりにします。元の読みを別に保持するため、3回目には元のひらがなへ戻れます。
- Enterで現在の表記を確定します。次の文字を打つと表示中の表記を確定して新しい入力を始めます。Escまたは削除の初回操作で切り替えを取り消して元の読みへ戻し、その後は通常の編集になります。
- 確定済み文章、選択範囲、過去の入力履歴はこのボタンの対象にしません。既存の「翻訳」メニューの選択範囲処理とは独立です。
- 画面内の地球儀・通常の非表示ボタンを削除しました。外付け接続時の表示ポリシー・省スペース・設定の完全非表示・Ctrl+Alt+K・復帰タイル・アプリの復帰操作は維持します。

## 辞書と文章翻訳

[JMdict](https://www.edrdg.org/jmdict/j_jmdict.html)の日本語・英語部分（218,995原項目）から、最初の2語義の短い英語と、同じ第一語義に対応するカタカナ語を抽出しました。読みと表記の416,944検索キー、1,006,730件の対応を含みます。この数は異なる英単語や正しい文章翻訳の件数を意味しません。生成物は圧縮9,591,369バイト、展開31,502,264バイトです。

通常の日本語変換は元のエンジンを使い、先頭の候補を維持します。読みが一致する先頭の日本語候補の表記を手掛かりにし、同じ読みの別単語の英語が混ざることを抑えます。設定した件数の範囲で末尾に最大8件の追加候補を確保します。学習ONで選択・確定した辞書の英語やカタカナも、同じ読みの候補として頻度順に上がります。Googleで翻訳した文章は学習へ保存しません。

英語切り替えでは、まず同梱辞書の選択中の表記、次に読みを検索します。見つからない文章は、取得済みの[Google ML Kitの端末内翻訳](https://developers.google.com/ml-kit/language/translation/android)を使います。モデルが未取得なら入力を保ち、既存の「設定 → 翻訳」で取得する案内を出します。自動でモデルをダウンロードしません。Googleの結果を表示している間は候補欄に結果と公式の帰属画像を並べます。

候補生成ごとに翻訳を実行することはありません。検索用ファイルの展開・検証はIOスレッド、予測検索はバックグラウンドで実行し、通常の変換時は読み取り専用のメモリマップから検索します。

## 入力の安全性

パスワード・数値・予測禁止欄では新しい切り替えを行いません。文字入力、モード変更、確定、カーソル移動、入力先の変更は進行中の翻訳を取り消します。翻訳完了時にも未確定状態の同一性・入力セッション・編集番号を確認し、古い結果で新しい入力を置き換えません。候補検索と切り替えで入力文を外部サーバーへ送信しません。

## 制限と出典

単語の語義選択は文脈を完全には理解せず、同音異義語やカタカナの関連語には複数の意味が含まれます。翻訳には誤りがあり、未登録語に英語を捏造したりローマ字で代用したりしません。モデル未取得・失敗時も元の入力を保持します。切り替えの上限は5,000文字です。
