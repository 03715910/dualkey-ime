# 物理キーボードの候補操作（0.1.9）

## 操作

- 日本語を入力し、Spaceまたは変換キーを押すと縦の候補一覧を開きます。Spaceを繰り返すか矢印・Tabで候補を選び、Enterで確定します。
- 「続きを」を確定した後にTabを押すと、続きの予測の先頭を選びます。さらにTab・矢印で切り替え、Enterで末尾へ追加します。Shift＋Tabで前へ戻ります。候補を選んでいる間も、確定済みの文章を置き換えません。
- 画面キーボードを完全非表示にしても、Space／変換キーや確定後のTabで候補一覧だけを表示します。操作前の見えない続きの候補のために、矢印を横取りしません。
- 候補がないTabは通常の入力欄移動としてアプリへ渡します。Escで候補選択を取り消し、新しい文字を打つと通常入力へ戻ります。
- Backspaceは表示されたUnicode文字を1つ消します。KA→か→削除→空、K→k→削除→空です。KYO→きょでは、最初の削除で小さい「ょ」、次で「き」を消します。漢字へ変換中の最初のBackspaceは、従来どおり変換を解除して読みに戻します。
- 日本語モードの疑問符・感嘆符・丸括弧などは全角です。句読点は「、。」、角括弧は「「」」、ハイフンは長音です。数字や英語モードの記号、パスワード欄の直接入力は変更しません。ローマ字のn'は「ん」の規則を保ちます。
- 半角／全角キーで日本語・英語を交互に切り替えます。長押しの繰り返しでは連続切り替えをしません。英数・かな・Ctrl＋Spaceも引き続き利用できます。

## 日本語配列と英語配列

Androidから通常の`KEYCODE_ZENKAKU_HANKAKU`が届けば、配列設定にかかわらず日英を切り替えます。一部の機器は同じ位置のキーを`KEYCODE_GRAVE`として通知するため、「物理キーボード → 半角／全角キーの互換動作」の日本語配列（初期値）では、修飾キーなしのGRAVEも切り替えに使います。英語配列の機器でバッククォートを入力する場合は、同項目を英語配列にしてください。Shiftを伴うキーやCtrl／AltなどのショートカットはGRAVE互換動作の対象外です。文字の実際の配列はAndroid側で設定します。

OSがIMEへ渡す前に処理するキーはアプリから取得できません。その場合はCtrl＋Spaceまたは画面の日英切り替えを利用します。実際のSamsung機器でのキー通知は、別途実物で確認が必要です。[Androidのキー定義](https://developer.android.com/reference/android/view/KeyEvent#KEYCODE_ZENKAKU_HANKAKU)と[AOSPのキーボードの対応表](https://source.android.com/docs/core/interaction/input/keyboard-devices)を参照しています。

## 候補ウィンドウ

候補一覧は、IMEのウィンドウトークンへ付属するフォーカスを取らない`TYPE_APPLICATION_PANEL`です。オーバーレイ権限・システム専用のウィンドウ権限・アクセシビリティサービスを要求しません。[InputConnection.requestCursorUpdates](https://developer.android.com/reference/android/view/inputmethod/InputConnection#requestCursorUpdates(int))と[CursorAnchorInfo](https://developer.android.com/reference/android/view/inputmethod/CursorAnchorInfo)の座標変換で、入力位置の近くへ表示します。下に収まらなければ上へ、位置が得られなければ画面下部へ配置します。完全非表示時は高さ0の候補ホストを表示し、`onComputeInsets`で入力領域を予約せず、候補だけをタッチ可能にします。パスワード・予測禁止欄では候補一覧を出しません。表示だけの切り替えでは未確定入力を終了させず、入力先を離れるときに確定処理を行います。

一覧は選択位置を含む最大7件を表示し、矢印などでページをまたいで全候補を巡回できます。通常の画面候補・一覧・追加検索は維持しています。入力終了、変換確定、取消、言語切り替え、範囲選択などで閉じます。配布・署名・更新処理や学習DBの形式は変更していません。

Android 15の検証環境では、候補ホストを表示するとOS自身のIMEナビゲーション／キャプション領域が下端に残ります。文字キーや独自の空白行は出しませんが、OSの操作領域まで消せるとは保証しません。確定直後のTabと非表示アニメーションの競合を避けるため、この高さ0のホストは現在の入力セッション中は保持し、入力先を離れるときや表示モードを切り替えるときに解除します。Samsungの標準操作を無効化したり、システム権限を要求したりしません。

## 表示／非表示ショートカットとShift

「設定 → 物理キーボード → キーの組合せを変更」で、通常表示と完全非表示を交互に切り替える1つの組合せを登録できます。初期値はCtrl＋Alt＋Kです。表示専用・非表示専用へ分けず、同じ組合せで両方向に切り替えます。

画面のチェック欄でCtrl／Alt／Shift／Metaを選び、文字・数字・F1〜F12を指定できます。「キーボードから登録」を押して、実際のキー操作から登録することもできます。文字や数字の単独キー・Shiftだけの組合せは登録できず、通常の入力や大文字入力を妨げません。Fキーは単独でも登録できます。組合せの一致は修飾キーまで確認し、Caps Lock・Num Lockは判定へ含めません。長押しの繰り返しでは切り替えません。

「保存」を押すまで設定を変更せず、キャンセルと初期値の復帰ができます。「表示／非表示ショートカットを使う」をOFFにすると停止します。従来の有効・無効設定を維持し、新しい組合せの2項目だけをDataStoreへ同時保存します。

英語入力のShiftとCaps LockはAndroidのキー情報に従います。Shift＋aでA、Shiftを離したaでa、Caps Lock＋aでAです。日本語モードでは従来どおりローマ字の大文字・小文字を区別しません。画面キーボードのShiftも1回・ダブルタップの既存動作を維持しています。
