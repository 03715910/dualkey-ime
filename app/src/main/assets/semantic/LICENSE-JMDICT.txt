DualKey modifications: select short English equivalents from the first two
non-obsolete senses; remove parenthetical explanations; join first-sense
English glosses to Japanese katakana loanwords; normalize reading lookup keys;
compile the subset into a read-only DKL1 index. These derived dictionary data
are distributed under CC BY-SA 4.0, without warranties. Neither EDRDG nor the
dictionary contributors endorse this application. The application's independent
source code is separately licensed and is not included in this data licence.
