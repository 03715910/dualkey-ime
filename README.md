# DualKey IME

Android用の独立したキーボードアプリです。**0.1.1は初期開発版**です。一般的な日本語IMEに相当する辞書品質やSamsung実機での動作を保証する段階ではありません。

配布サイト：[DualKey IME](https://03715910.github.io/dualkey-ime/)。Androidスマートフォンで開き、「APKをダウンロード」からインストールします。

## Android Studioで開く

Android Studioの「Open」から、この`DualKeyIME`フォルダーを選びます。Gradleの同期を待ち、「app」を選んで接続したAndroid端末に実行してください。Android 8.0（API 26）以上に対応します。

検証に使用した構成：Android SDK/target 35、AGP 8.8.2、Gradle 8.10.2、Kotlin 2.2.20、JDK 21（コンパイル出力17）。手元のSDKとの互換性を優先して固定しています。

```powershell
$env:JAVA_HOME = 'C:\Program Files\Android\Android Studio\jbr'
.\gradlew.bat :app:assembleDebug :core:test :app:lintDebug
```

デバッグAPKは`app/build/outputs/apk/debug/app-debug.apk`です。デバッグ版はアプリID末尾が`.debug`になり、正式配布版と共存します。正式な更新フィードはデバッグ版には適用できません。

## スマートフォンで使う

1. リリースAPKを端末へコピーするか、公開済みの場合は専用サイトから取得します。
2. ファイルを開き、Androidの案内に従ってインストールします。必要ならダウンロードに使ったブラウザなどの「不明なアプリのインストール」を許可します。
3. DualKey IMEを開き「キーボードを有効にする」から有効化します。AndroidのIME警告を読んでください。
4. 「使用するキーボードを選択」でDualKeyを選び、メモアプリなどの入力欄をタップします。

日本語は中央・左・上・右・下のフリックで入力します。「゛゜小」で直前のかなを濁音・半濁音・小文字へ順に変更します。数字行は設定から変更できます。「あ / EN」で日本語・英語を切り替えます。英語のShiftは1回で次の1文字、素早い2回押しで大文字固定、固定中に押すと解除します。

## Bluetooth・USBキーボード

接続はAndroidの標準設定で行います。Bluetooth権限やUSBの独自ドライバーは必要ありません。

| 操作 | キー |
| --- | --- |
| 日本語・英語切り替え | 半角/全角、英数、かな、Ctrl + Space |
| 変換・次の候補 | Space |
| 候補の移動 | 矢印 |
| 文字・候補の確定 | Enter |
| 変換解除／未確定入力の取消 | Esc |
| 削除 | Backspace |
| 画面キーボードの表示切り替え | Ctrl + Alt + K |

日本語はKYO→きょ、KYOUHA→きょうは、NIHONGO→にほんごなどに対応します。物理キーの配列・Shift・Caps LockはAndroidのUnicodeキー情報に従います。配列が合わないときは設定画面からAndroidの物理キーボード設定を開いてください。OSがショートカットを先に使う場合は、画面の操作をご利用ください。

初期状態では物理キーボードの接続時に完全非表示、切断時に通常表示になります。接続中に手動で通常表示を選ぶと、その接続中の選択を維持します。「前回の手動選択を記憶」を有効にすると、次の接続時にも使います。省スペース表示では候補・入力モード・再表示ボタンを残します。

完全非表示からの画面操作による復帰は、ホーム画面からDualKeyを開き「画面キーボードを通常表示に戻す」を押します。クイック設定の編集から「DualKeyを表示」タイルも追加できます。Androidの仕様上、フォーカスがない別アプリの入力欄を強制的に開くことはできないため、タイルはDualKeyのテスト入力欄を開きます。目的のアプリへ戻って入力欄をタップしてください。

## 変換と翻訳

現在の日本語変換は本プロジェクト用の小規模辞書と最長一致による簡易文章変換です。複数候補、ひらがな／カタカナ、前方一致の予測、ユーザー辞書を備えています。**Mozcは未導入**で、未知語・文節解析・長文の品質には制限があります。英語予測も小規模です。

翻訳はGoogle ML Kitによる端末内の日英相互翻訳です。IMEの未確定テキスト、またはユーザーが選択しているテキストが対象です。翻訳方向を選び、結果を確認してから確定します。初回の日本語モデル（約30MB）の取得にはWi-Fiが必要です。プレビューの直接編集、任意の確定済み全文の取得・置換は実装していません。パスワード欄では予測、翻訳、未確定文字プレビューを無効にします。

## 配布・更新

配布設定は`distribution.properties`に集約し、専用リポジトリと実際の配布先を設定しています。サイトの元ファイルは`site/`です。公開するパッケージ名は`io.github.user03715910.dualkey`です。以前の配布先未設定のローカル0.1.0からは、サイトのAPKを一度手動で上書きインストールしてください。

サイトと`version.json`をGitHub Pages、APKと過去バージョンをGitHub Releasesに配置します。APKをGit履歴に蓄積しないため、この組み合わせを採用しています。ソースの通常コミットでは公開しません。署名鍵をPC内に保管したまま、明示的な`tools/publish_local_release.py --confirm PUBLISH`でリリースとサイトを更新します。生成済みサイト専用の`gh-pages`ブランチへ反映し、GitHub Pagesの標準Actionsがデプロイします。署名用Secretsは未登録です。

アプリは起動時（過剰な再確認を避け約1時間の間隔）、約12時間ごとのWorkManager、設定ボタンで更新確認します。自動ダウンロードは初期OFF、Wi-Fi限定は初期ONです。WorkManagerの実行時刻はOSの都合で変動します。検出・ダウンロードは入力を妨げず、インストール画面は利用者がボタンを押したときだけ開きます。

HTTPS、公式URL、容量、SHA-256、APK暗号署名、ピン留めした証明書、現在のアプリとの署名一致、アプリID、versionCodeを確認します。署名鍵のローテーションは現段階では受け付けず、同じ署名鍵の更新だけを許可します。更新に失敗しても既存アプリを削除しません。必須更新の指定でも入力をロックしません。

公開・署名鍵・Secrets・復旧手順は[リリース手順](docs/RELEASE.md)、設計と公式調査は[設計メモ](docs/ARCHITECTURE.md)、試験の実施区分は[テスト結果](docs/TEST_RESULTS.md)、今回の成果物と導入案内は[開発報告](docs/DELIVERY_REPORT.md)にまとめています。

## プロジェクト構成

| 場所 | 役割 |
| --- | --- |
| `core/` | Androidに依存しないローマ字入力、変換インターフェース、表示ポリシー、更新URL検証 |
| `app/.../ime/` | InputMethodService、フリックView、英語QWERTY、物理キー、表示制御、タイル |
| `app/.../data/` | DataStore設定とユーザー辞書 |
| `app/.../translation/` | Google ML Kit翻訳、モデル管理 |
| `app/.../update/` | メタデータ、HTTPS取得、APK検証、WorkManager |
| `app/.../settings/` | 導入案内、設定、更新インストール案内 |
| `site/` | スマートフォン対応の配布サイト |
| `tools/` | 署名鍵作成、配布物の検証・生成、公開後検証 |
| `.github/workflows/` | 開発用CIと明示的な公開操作 |

入力内容をログに出力せず、更新通信には含めません。翻訳文は端末内で処理しますが、Google ML Kitはモデル配布と利用状況・診断に通信を使います。詳しくは[Googleのデータ開示](https://developers.google.com/ml-kit/android-data-disclosure)を参照してください。
