GET STARTED

使いはじめるまで、3ステップ。

  1. APKをダウンロード

    このページのボタンから取得します。ダウンロードが終わったらファイルを開いてください。

  2. Androidでインストール

    必要に応じて、ブラウザからの「不明なアプリのインストール」を許可し、Androidの確認画面でインストールします。

  3. DualKeyを有効にする

    アプリを開き「キーボードを有効にする」→「使用するキーボードを選択」と進みます。OSのIME警告を確認してください。

PHYSICAL KEYBOARD

机では、物理キーボード。

Bluetoothでペアリング、またはUSBで接続します。初期設定では文字キーの画面を自動で隠し、切断すると戻ります。

画面入力へ戻すには Ctrl + Alt + K。使えない端末ではアプリの「通常表示に戻す」か、クイック設定の「DualKeyを表示」タイルを利用してください。

日本語に切り替え
画面の「あ / EN」、半角/全角・かな・英数キー、Ctrl + Space
漢字へ変換
Space → 矢印で選択 → Enterで確定。Escで変換解除。
画面を少しだけ使う
設定で「省スペース表示」を選ぶと候補欄と操作ボタンを残せます。
配列が合わないとき
Androidの物理キーボード設定で日本語／英語配列を確認してください。

よくある質問

アプリは自動で更新されますか？

0.1.3以降は起動時に新バージョンを案内します。「更新する」を押すとアプリ内で取得・検証し、Androidの確認画面へ進みます。下部の「更新」からも確認できます。定期確認と自動ダウンロードは設定に従い、最後のインストールはAndroidの許可・確認を行います。

更新すると辞書や設定が消えますか？

同じアプリIDと署名鍵で更新する場合、設定とユーザー辞書は保持されます。アンインストールすると消えるため、更新のために削除しないでください。

変換精度は一般のIMEと同じですか？

0.1.5では単漢字・異体字を拡充し、候補は最大1,000件まで検索できます。「一覧」から50件ずつ追加表示できます。日本語の学習がONなら、確定した語句の読み・表記・使用回数・最終使用時刻を端末内に保存し、よく使う候補を変換・予測の上位へ表示します。設定から停止・削除でき、パスワードや学習禁止の欄では保存・利用しません。長文・未知語の変換や端末フォントによる字形表示には制限があります。

翻訳はオフラインでも使えますか？

初回にWi-Fiで日本語モデル（約30MB）を取得した後は、端末内で日英相互翻訳を行います。Google ML Kitのモデル配布・診断通信が発生する場合があります。パスワード欄では翻訳と予測を無効にします。

Samsungで画面表示やインストールがうまくいきません

端末の「画面キーボードを表示」、ショートカット設定、Samsungのセキュリティ設定が影響する場合があります。端末の警告と管理者の設定に従ってください。このページは実機確認済みであることを保証しません。

開発者確認制度には対応していますか？

配布元の本人確認とアプリ登録は、Android Developer Consoleなどで別途必要になる場合があります。対象地域・配布方法・端末条件により異なります。Android公式の最新情報を確認してください。

ご利用の前に

現在は初期開発版です。大切な文章を入力する前に動作を確認してください。IMEは入力内容に触れるため、信頼できる配布元からのみインストールしてください。更新APKは容量・SHA-256・暗号署名・アプリIDを検証します。入力中に更新を強制しません。

他社のキーボードとは関係のない独立したアプリです。必要な権限は通信、通知、振動、Android標準インストール案内に限定します。
